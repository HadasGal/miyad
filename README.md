# מיד

מיד ליד, ומיד. לוח מסירות לקהילה סגורה.

מפרסמים בשנייה, רואים מה עוד זמין, ומקבלים התראה כשמה שחיפשת מופיע.
שכבת סדר מעל קבוצת הווצאפ, לא תחליף לה.

**לינק חי: https://miyad.vercel.app** · בלי הרשמה, לוחצים "צפייה בדמו".

## הרצה

```
npm install
npm run dev
```

ופותחים את הכתובת שמופיעה בטרמינל (בדרך כלל http://localhost:5173). הכי טוב במצב מובייל בכלי המפתחים.

## איך לשחק בדמו

במסך הפתיחה לוחצים "צפייה בדמו". אפשר גם לנסות את "הצטרפות": זו זרימת הרשמה מדומה, בלי מייל אמיתי.

בתוך הדמו, הפס הכהה למעלה מחליף פרופיל. כדאי לנסות:

1. **התור:** בפרופיל של דנה, לפתוח את הספה וללחוץ "לתת למיכל". לעבור למיכל ולראות "זה שמור לך אצל דנה". לחזור לדנה וללחוץ "לא נאסף", והתור עובר לנועה.
2. **מחכה בחוץ:** בפרופיל של מיכל, לפתוח את הספלים של שולה וללחוץ "לקחתי". לעבור לשולה ולראות את העדכון ואת "זה עדיין שם".
3. **התראה:** למיכל יש חיפוש שמור על "ספה". לעבור לדנה, לפרסם פריט עם המילה ספה בכותרת, ולחזור למיכל. הפעמון יראה עדכון.
4. **פרסום:** לצלם או לבחור תמונה, וה-AI המדומה ימלא כותרת וקטגוריה (בדמו ההצעה לא קשורה לתמונה, וזה כתוב במסך). בסוף, כרטיס מוכן לשיתוף בקבוצה.

"איפוס" מחזיר את נתוני הדמו להתחלה, ו"יציאה" חוזרת למסך הפתיחה.

## מבנה

```
src/
  store.jsx          כל הכללים של המוצר: תור, דילוג, נמסר, נלקח, התראות
  data/mockData.js   הקהילה המדומה. נעלם כשעוברים ל-Firebase
  screens/           לוח, עמוד פריט, פרסום, שלי, התראות
  components/        אייקונים, כרטיסים, ניווט, מחליף משתמשות
  styles.css         השפה העיצובית במשתני CSS, כולל מצב כהה
```
