# מיד

מיד ליד, ומיד. לוח מסירות לקהילה סגורה.

מפרסמים בשנייה, רואים מה עוד זמין, ומקבלים התראה כשמה שחיפשת מופיע.
שכבת סדר מעל קבוצת הווצאפ, לא תחליף לה.

## הרצה

```
npm install
npm run dev
```

ופותחים את הכתובת שמופיעה בטרמינל (בדרך כלל http://localhost:5173). הכי טוב במצב מובייל בכלי המפתחים.

## איך לשחק בדמו

הפס הכהה למעלה מחליף משתמשת. נסי:

1. **התור:** כדנה, פתחי את הספה ולחצי "לתת למיכל". עברי למיכל ותראי "דנה שמרה לך את זה". חזרי לדנה ולחצי "לא נאסף", והתור עובר לנועה.
2. **מחכה בחוץ:** כמיכל, פתחי את הספלים של שולה ולחצי "לקחתי". עברי לשולה ותראי את העדכון ואת "זה עדיין שם".
3. **התראה:** כמיכל, יש לה חיפוש שמור על "ספה". עברי לדנה, פרסמי פריט עם המילה ספה בכותרת, וחזרי למיכל. הפעמון יראה עדכון.
4. **פרסום:** צלמי או בחרי תמונה, וה-AI המדומה ימלא כותרת וקטגוריה. בסוף, כרטיס מוכן לשיתוף בקבוצה.

"איפוס" מחזיר הכל להתחלה.

## מבנה

```
src/
  store.jsx          כל הכללים של המוצר: תור, דילוג, נמסר, נלקח, התראות
  data/mockData.js   הקהילה המדומה. נעלם כשעוברים ל-Firebase
  screens/           לוח, עמוד פריט, פרסום, שלי, התראות
  components/        אייקונים, כרטיסים, ניווט, מחליף משתמשות
  styles.css         השפה העיצובית במשתני CSS, כולל מצב כהה
```
